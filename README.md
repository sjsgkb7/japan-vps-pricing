## 三网精品回程到底解决什么问题

CN2 是中国电信的骨干网 ChinaNet Next Carrying Network。在 VPS 语境下说“CN2”，通常指 CN2 GIA（Global Internet Access），是电信精品网络中优先级最高的一档，走专用通道，遇到拥塞被降级或丢包的概率远低于普通 163 线路（AS4134）。联通 AS9929 和移动 CMIN2 是另外两家运营商对应的精品回程产品。

GoMami 日本节点把这三条同时接进来，电信用户走 CN2、联通用户走 9929、移动用户走 CMIN2，各走各的优化路径。这也是它比普通日本 VPS 贵的主要理由——精品带宽的采购成本本身就高。
